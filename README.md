# Student-management-system
A console based student management system built with pytthon

Features

- Add students
- View students
- Search students by roll number
- Delete students
- Calculate student averages
- Update student information
- Calculate grades
- Save student data to a JSON file
- Load previously saved student data

Technologies Used

- Python
- JSON
- File Handling

Python Concepts Practiced

- Variables and data types
- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements
- User input
- Exception handling
- JSON file handling

About the Project

I built this project to practice Python fundamentals and understand how different Python concepts can be combined to create a working application.

The program uses a menu-driven system to manage student information such as names, roll numbers, and marks.

Student data can be saved to a JSON file and loaded again when needed.

What I Learned

Through this project, I practiced working with data structures, functions, file handling, JSON, and basic program logic while building a complete small application.
